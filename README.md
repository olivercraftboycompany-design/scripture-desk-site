Scripture Desk — static website deployment.

Public-domain Scripture: World English Bible, Douay–Rheims, Clementine Vulgate, Brenton’s English Septuagint (1851), and the historic Russian Synodal Bible (1876), via [Bolls Bible](https://bolls.life/). The [Catholic Public Domain Version](https://www.sacredbible.org/catholic/version.htm) by Ronald L. Conte Jr. is also public domain. The English Orthodox reading set pairs Brenton’s Septuagint with the WEB New Testament.

## Bibley AI

The website is static and does not run the Bibley Python model on GitHub Pages. The Study panel can open the same passage in Scripture Desk’s local Bibley mode after you set it up on your computer. The live reader remains usable without AI, including all of its Scripture editions and the Copy study prompt action. Local Bibley uses KJV references and does not compare traditions. No questions are sent through GitHub Pages.
